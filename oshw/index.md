# ZuluSCSI Pico オープンソースハードウェア設計

<a href="https://certification.oshwa.org/us002581.html"><img src="certification-mark-US002581-stacked.png" style="max-width: 100%; height: 200px;"></a>

**2023年11月18日** - ZuluSCSI Pico OSHW Rev 2023dは、Open Source Hardware Associationによって
<a href="https://certification.oshwa.org/us002581.html">オープンソースハードウェア</a>
として認定されました。

**2023年10月10日** - RP2040ベースのZuluSCSIファミリーのSCSIドライブエミュレーションデバイスの開発元であるRabbit Hole Computing™は、[ZuluSCSI™ Pico OSHW](https://github.com/ZuluSCSI/ZuluSCSI-Pico-OSHW)のボードレイアウトおよび設計ファイルを[CERN OHL-S 2.0](https://spdx.org/licenses/CERN-OHL-S-2.0.html)（強い相互主義のバリアント）ライセンスの下で公開しました。

貢献や質問を歓迎します。質問がある場合は、[こちらのリポジトリのディスカッションセクション https://github.com/ZuluSCSI/ZuluSCSI-Pico-OSHW/discussions](https://github.com/ZuluSCSI/ZuluSCSI-Pico-OSHW/discussions) でお気軽にどうぞ。
